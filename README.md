# devnotes — Agentic Coding Second Brain

Personal knowledge base for tracking the agentic coding landscape, maintained with Claude Code.

- `notes/` — my own dated observations and brain dumps
- `field/` — agent-generated summaries of new developments, biased toward what my notes suggest I care about
- `synthesis/` — agent-generated suggestions for consolidation and cross-linking (read-only, for my review)
- `archive/` — rolled-up originals organized by summary level
- `templates/` — reusable note templates
